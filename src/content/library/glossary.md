- **LLM** — a language model trained to predict text; the engine behind most assistants.
- **Prompt** — the instructions and context you send to a model.
- **Agent** — a system that uses a model to decide on steps and call tools.
- **Hallucination** — a confident answer that is wrong or invented.
- **RAG** — retrieval-augmented generation: the model answers using documents fetched at question time.
- **Prompt injection** — hidden instructions in content that try to hijack the model.
- **Token** — a chunk of text; usage and cost are measured in tokens.
