## Set up

1. Install the [Code Assistant](/tools/code-assistant/) extension from the software portal.
2. Verify: public-code matching filter **on**, telemetry sharing **off**.
3. Add the [Code Review Agent](/agents/code-review-agent/) to one repository.

## Habits that pay off

- Ask for tests first, then the implementation.
- Never paste secrets or production data into the chat.
- Read every line you commit: use the [AI code review checklist](/library/ai-code-review-checklist/).
